**SNAP Facebook Network Explorer**
 基于 SNAP 数据集的 Facebook 社交网络可视化分析平台

------

## 一、项目背景与目标

本项目旨在利用 SNAP 提供的 Facebook 社交关系数据集（facebook.txt），
 通过 D3.js 实现一个 可交互的 Web 可视化界面，
 展示 Facebook 用户之间的好友关系网络。

用户可以：

- 直观观察好友关系图谱；
- 通过力导向布局了解社群结构；
- 与节点交互（点击、悬停、筛选等）以探索用户间的连接模式。

------

## 二、前期准备

### 1. 数据准备

- **数据来源：** SNAP 的 `facebook_combined.txt`

  - 文件中每一行格式为：

    ```
    0 1
    0 2
    0 3
    ...
    ```

    表示用户 0 与用户 1 是好友。

- **处理目标：** 将该文本转化为 JSON 格式供 D3.js 使用。用 Python 做一次性数据清洗

------

### 2. 软件与环境准备

| 类别         | 名称                                                         | 作用                           |
| ------------ | ------------------------------------------------------------ | ------------------------------ |
| 前端框架     | **D3.js **                                                   | 绘制交互式力导向图             |
| Web 运行环境 | **VS Code + Live Server 插件** 或 **本地 Python HTTP 服务器** | 在浏览器中运行项目             |
| 数据处理     | **Python (可选)**                                            | 转换 SNAP txt 文件为 JSON 格式 |
| 浏览器       | **Chrome / Edge**                                            | 运行和调试前端界面             |

------

## 三、实现模块

1. **数据加载模块**
   - 使用 D3.js 的 `d3.json()` 读取 `graph.json` 文件。
2. **力导向图绘制模块**
   - 使用 `d3.forceSimulation()` 创建物理仿真；
   - 包括节点碰撞、连线约束、重力中心等力的配置；
   - 节点和连线用 SVG 元素渲染。
3. **交互模块**
   - 鼠标悬停显示节点信息；
   - 拖拽节点重新布局；
   - 点击节点高亮其邻居；
   - 可添加搜索框定位某个用户。
4. **界面美化**
   - 背景渐变；
   - 节点颜色区分不同社群；
   - 动态标题与提示框。

------

## 四、最终呈现效果

当你在浏览器打开网页时，可以看到：

**页面结构**

- 主体：一个可交互的力导向图（Facebook 用户网络）
- 侧栏或悬浮框：节点信息、搜索框

**交互体验**

- 鼠标悬停：节点高亮、显示用户 ID
- 拖拽节点：布局自动调整
- 点击节点：显示与该节点相连的好友
- 动态动画：节点之间连线有弹性、自然摆动

**可扩展功能**（可选）

- 节点按社群或度数着色
- 网络统计信息显示（节点数、连边数、平均度等）
- 图谱缩放与平移（zoom & pan）

## 六、启动网页服务器

在项目根目录下以管理员身份打开终端，运行以下命令：使用 Python 启动本地服务器

```cmd
python -m http.server 8000
```

在浏览器中输入：

```
http://127.0.0.1:8000/
```

即可看到交互式可视化页面。
